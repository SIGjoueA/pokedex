# Pokédex (FR) – PWA hors-ligne

Site statique dans `docs/` (HTML/CSS/JS sans framework ni backend), publié par GitHub Pages (branche `main`, dossier `/docs`) :
https://sigjouea.github.io/pokedex/

## Fonctions
- Recherche instantanée sans accents (nom FR / EN / JA / romaji, ou numéro), filtres type / génération / catégorie / tri, plus « Capacité… » et « Talent… » (autocomplétion française, jeu et méthode d’apprentissage, v60.37), grille ou liste.
- **Jeux** : Pokémon HOME, Pokémon GO, puis 28 jeux (série principale, Légendes et DLC) du plus récent au plus ancien, et 3 listes en plus : **Méga-Dex Z-A** (espèces ayant une Méga dans la sauvegarde Z-A, forme de base + Méga, ordre national), **Hors dex Écarlate/Violet** et **Hors dex Épée/Bouclier** (espèces obtenables par transfert / échange / événement mais absentes de tous les Pokédex de la sauvegarde ; marques dans le jeu de base). Dans la liste, chaque liste en plus est placée juste **au-dessus** de la dernière extension de son jeu : Méga-Dex Z-A au-dessus de Méga-Dimension, Hors dex É/V au-dessus du Disque Indigo, Hors dex É/B au-dessus de Couronneige (v22). Un jeu sans extension choisi = Pokédex régional, puis en fin de liste toutes les espèces obtenables absentes du Pokédex régional (transfert Pal Park / Poké Transfert / Bank / HOME, échange, événement, Méga) marquées « Hors dex », ordre national. Une espèce présente dans un autre Pokédex de la même sauvegarde (Z-A ↔ Méga-Dimension…) n'est jamais « Hors dex ». Source : PokéAPI (espèce avec une liste de capacités dans le groupe de versions du jeu = présente dans les données du jeu), `build/fetch-obtainable.mjs` + `build/apply-hors-dex.mjs` (exceptions manuelles documentées dans le script). Les marques « hors dex » ne changent pas la complétion.
- **Formes** (bouton dans l'en-tête, masquées par défaut) : régionales, Méga, Primo, Gigamax, multi-formes (Zarbi, Flabébé, Vivaldaim…), mâle/femelle. Sélecteur de formes sur la fiche.
- **Fiche par jeu** : stats / types / talents / objets tenus / attaques / évolutions tels qu'à l'époque du jeu, Pokédex FR, numéros régionaux.
- **Pokémon GO** : stats ATT/DEF/END, PC max (niv. 40, 50 et 51), attaques avec DPS, distance compagnon, coûts d'évolution, shiny, statut de sortie, costumes, formes Obscur / Purifié, classements PvP, raids, Combats Max et Team GO Rocket.
- Modes **Collection** (journal des Pokémon que vous possédez) et **Pocket** (cartodex TCG Pocket).
- Capturés (Poké Ball), shiny et favoris dans `localStorage` (`caught`, `shiny`, `favs`) ; export / import JSON.
- Hors-ligne : service worker (coquille + données). Pack images HOME (~17 Mo, peut se lancer tout seul hors connexion mesurée), pack des fiches et formes (~35 Mo), illustrations shiny HOME en option (~16,4 Mo, jamais automatique). Les sprites animés (GIF Showdown, ~307 Mo au total) ne sont dans aucun pack.

## Lancer en local
    python3 -m http.server 8765 --directory docs
puis http://localhost:8765 (le service worker exige localhost ou HTTPS).

## Reconstruire les données (Node 20+, Internet)
    cd build && npm install
    node fetch-pokeapi.mjs   # PokéAPI -> build/.cache (reprise possible, concurrence limitée, nouvelles tentatives)
    node fetch-extra.mjs     # encounters, locations, TM/HM machines (PokéAPI) + GO egg pool (Leek Duck) -> build/.cache
    node fetch-go.mjs        # PokeMiners game_masters + pogoapi.net -> build/.cache
    node fetch-images.mjs    # illustrations -> docs/img/{clé}.webp (256 px) et docs/img/s/{clé}.webp (shiny)
    node fetch-home.mjs         # rendus HOME -> docs/img/h/{clé}.webp
    node fetch-home-shiny.mjs  # rendus HOME shiny -> docs/img/hs/{clé}.webp (v60.34)
    # textes Pokédex seulement en anglais (traduction automatique, une seule fois ; résultat versionné : build/translations-fr.json)
    #   node translate-prep.mjs && python3 translate.py && python3 translate-fix.py   (pip install argostranslate)
    node build-data.mjs      # -> docs/data/*.json (efface et recrée docs/data)
    node fetch-mega-stones.mjs   # -> docs/data/mega-stones.json (à relancer après build-data)
    node apply-go-overrides.mjs  # (déjà lancé par build-data) Méga récentes + Gigamax GO depuis build/go-overrides.json, idempotent
    node fetch-cries.mjs     # v29 : cris (dépôt PokéAPI « cries ») -> docs/cries/*.mp3 + docs/data/cries.json (relançable, cache build/.cache/cries)
    node fetch-obtainable.mjs && node apply-hors-dex.mjs   # -> Hors dex (dex/*.json x, dex/hors-sw|sv.json, sp hx)
    python3 make-mega-energy.py  # -> icônes Méga-énergie GO (docs/img/energy, docs/data/mega-energy.json)
    node audit.mjs           # vérifications de cohérence (~800 faits connus)
    node make-icons.mjs      # icônes PWA (facultatif)
    node test.mjs 8765       # tests Chrome headless (360 px et 1000 px), captures dans ../screenshots
Après toute modification de `docs/`, incrémenter `VERSION` dans `docs/sw.js` (et `DATA_VERSION` si le format des JSON change).

## Règles de numérotation régionale
Les Pokédex viennent de PokéAPI (`/pokedex/{nom}`). Jeux à plusieurs Pokédex : fusion dans l'ordre indiqué, un Pokémon garde le numéro de son premier Pokédex (le Pokédex d'origine est affiché) :
- Écarlate/Violet : Paldea → Kitakami → Myrtille (664) ; Épée/Bouclier : Galar → Isolarmure → Couronneige (584) ; X/Y : Centre → Côtes → Monts (457).
- Soleil/Lune et Ultra-Soleil/Ultra-Lune : Pokédex d'Alola (numéro principal) ; les numéros par île sont indiqués sur la fiche.
- Légendes Z-A : Pokédex de Lumiose ; Méga-Dimension : Pokédex Hyperespace. DLC de SV / EB : leur propre Pokédex.
- HOME et GO : ordre national.
Exclus : Colosseum / XD (aucun Pokédex régional dans PokéAPI), Pokémon Champions (jeu de combat), versions japonaises Rouge/Vert/Bleu (même Pokédex que Rouge/Bleu).

## Formes
Les formes proviennent de `pokemon` / `pokemon-form` de PokéAPI. Femelles : formes « dimorphisme » ajoutées d'après les rendus HOME quand `has_gender_differences` (à partir de la génération IV). Sont exclus : Totems, Pikachu casquettes cosplay, formes sans illustration. Les formes identiques à l'octet près à une autre sont fusionnées (`build/art-dupes.json`). Pitrouille / Banshitrouye : tailles « Taille S / M / L / XL » (les 4 formes, même illustration). Mégas multiples : « Méga X / Y / Z », « Méga ♂ / ♀ », « Méga Passé » (Magearna), « Méga Courbée / Affalée / Raide » (Nigirigon). Compteur en mode Formes : « N formes (+ M formes de combat, non comptées) », N = dénominateur. Libellé de la forme de base sans nom officiel (jamais « Normal ») : « Commun » si l'espèce a des formes régionales (officiellement « de Kanto »…) ou d'autres formes, « Mâle » s'il n'y a qu'un dimorphisme sexuel en plus des Méga/Gigamax ; les noms officiels restent (Deoxys/Terapagos Forme Normale, Arceus/Silvallié type Normal, Keldeo). Disponibilité d'une forme par jeu : déduite des données d'attaques de PokéAPI + règles (Gigamax = Épée/Bouclier, Méga = jeux compatibles et Pokédex du jeu, féminin ≥ gén. IV), précisée en v60.29 (Méga du DLC Z-A, formes régionales, Gigamax).

## Pokémon GO
Source principale : PokeMiners `game_masters` (`latest/latest.json`, daté dans `go.json`) ; liste des Pokémon sortis / shiny / Méga : pogoapi.net. PC max = formule officielle `floor((ATT+15)·√(DEF+15)·√(END+15)·cpm²/10)`, vérifiée (Mewtwo 4 724, Leuphorie 3 117 au niveau 50). Aucune valeur n'est inventée : une donnée absente n'est pas affichée (la distance d'éclosion n'est pas dans la source ; le statut shiny est au niveau espèce). Pied de page : « Données GO : communautaires, non officielles ».

**Overrides manuels GO (v28)** : `build/go-overrides.json` (édité à la main, **jamais écrit par les scripts**) est appliqué par `build/apply-go-overrides.mjs`, lancé automatiquement à la fin de `build-data.mjs` et relançable seul (idempotent). Il contient : (1) les Méga sorties dans GO après le gel de la liste pogoapi `mega_pokemon` (Méga-Raichu X/Y, Empiflor, Staross, Dracolosse, Mewtwo X/Y, Airmure, Étouraptor, Blindépique, Goupelin, Amphinobi, Sepiatroce, Hexadron ; une Méga sans stats dans le game master reçoit les attaques de sa base et la note « stats à venir ») ; (2) la liste des Gigamax de GO avec date de sortie (`from`, la forme apparaît automatiquement dans l’app à partir de ce jour : Duralugon le 2026-11-06) et la disponibilité shiny (`shiny`, `shinyFrom` ; pas de shiny pour Lézargus). **Mise à jour GO hebdomadaire** : après `fetch-go.mjs` + reconstruction (ou toute modification de `docs/data`), toujours relancer `node apply-go-overrides.mjs` (sans effet si déjà appliqué ; met aussi à jour le pool d’œufs courant et l’ajoute à l’historique, `node update-go-eggs.mjs`) puis `node audit.mjs`, qui échoue si une Méga ou un Gigamax de la liste a perdu son statut GO. Ajouter une Méga / un Gigamax nouvellement sorti = éditer `go-overrides.json` (sources : Bulbapedia « Mega Evolution (GO) », « Gigantamax (GO) »), retirer de la liste une Méga que pogoapi connaît n’a pas d’effet.

## Rencontres, CT/CS, œufs GO, textes traduits
- **Rencontres** : jeux Switch (y compris Légendes Arceus, Écarlate / Violet, Z-A, DEPS, RF/VF Switch) via Poképédia (`f.pl`, v32) ; anciens jeux : rencontres PokéAPI, complétées par les lieux et méthodes Poképédia (v42, v60.22) quand une fiche n’avait rien.
- **CT / CS / DT** : PokéAPI `machine` par groupe de versions (ex. « CT24 »), affichés dans l'onglet CT/CS.
- **Œufs GO** : le **pool de la saison en cours** (distance 1/2/5/7/10/12 km, Aventure Synchro, cadeaux) est lu sur la page Leek Duck « Eggs » (communautaire ; la date indiquée est celle de la dernière mise à jour du tableau Leek Duck, pas celle du début de saison). L’**historique par saison** (et les périodes d’avant 2020, libellés normalisés en français, plus récente en haut) vient des archives Serebii « Previous Egg Pokémon », unionné chaque semaine avec le pool Leek Duck courant (`build/update-go-eggs.mjs`, aussi lancé par `apply-go-overrides.mjs`) sans effacer les saisons passées. Fiches : « Éclosion d’œuf (pool actuel) » et « Déjà sorti en œuf » (saison et distance si connues). Noms français des saisons : Poképédia (CC BY-NC-SA 3.0 FR), confirmés sur le site officiel quand une page existe. Aucune valeur inventée : une saison ou une éclosion douteuse est laissée vide et signalée.
- **Textes Pokédex** : les textes officiels français (PokéAPI ou Poképédia, v57 / v60.22) priment. Une traduction automatique (Argos Translate, signalée « Traduit en français faute de données officielles ») n’apparaît qu’en dernier recours.

## Noms (FR / EN / JA / romaji)
En-tête de chaque fiche : nom français, puis genus · nom anglais, puis nom japonais · romaji. Les noms d'espèces viennent de PokéAPI (`ja-Hrkt`/`ja`, `ja-roma`). Formes : nom anglais = nom de forme PokéAPI (« Alolan Raichu »), sinon « Espèce (libellé de forme) » ; japonais = nom de forme PokéAPI s'il contient le nom de l'espèce (メガフシギバナ), « région + espèce » pour Alola/Galar/Hisui/Paldea (アローラライチュウ), sinon « espèce（libellé japonais de la forme） » ; les formes sans libellé japonais dans PokéAPI (femelles, Charmilly, Pichu Troizépi, Amphinobi Synergie) affichent le nom de l'espèce. Romaji des morceaux de forme : translittération Hepburn automatique (`build/names.mjs`) accolée au romaji PokéAPI de l'espèce. La recherche couvre FR, EN, japonais (hiragana ou katakana) et romaji, sans accents ni casse.

## Suivi des captures
- **Système d'icônes** (identique dans légende, filtre Catégorie, cartes et compteurs ; les `<option>` natives utilisent des emojis équivalents) : Poké Ball rouge 🔴 = capturé dans ≥ 1 jeu (GO compris) ; **Poké Ball dorée** 🟡 = complété, Poké Ball dorée seule = complété jeux actuels (tous les jeux Switch où il existe, plus Pokémon GO s’il y est disponible ; un jeu et ses extensions comptent pour un) ; Poké Ball dorée + 🕹 = complété dans les anciens jeux (les deux niveaux = dorée + 🕹) ; icône HOME 🏠 bleue = transféré depuis ≥ 1 jeu, **HOME dorée** 🟡🏠 = transféré depuis tous les jeux compatibles où il existe (GO compte, sauf Pokémon fabuleux qui ne peuvent pas sortir de GO) ; ✨ = shiny (simple, par jeu ; pas de complétion shiny). GO compte pour « capturé » et pour la complétion jeux actuels (même palier que Switch). Vue de base : lecture seule, dérivée des marques par jeu ; le détail liste l'état par jeu.
- **Migration** : les anciennes marques globales `caught`/`shiny` sont conservées comme « marques manuelles de l'ancienne version » : comptées comme capturé/shiny dans la vue de base, indiquées comme telles dans le détail avec un bouton « Retirer ». Elles ne servent à aucune complétion. Les favoris (`favs`) restent globaux.
- Un jeu ou Pokémon GO choisi dans « Jeux » : marques par jeu et par forme, `caught_g`, `shiny_g` (`"rb:25"`, `"sw:26-alola"`), compteurs et filtres Catégorie propres au jeu.
- **Transféré vers HOME (v22 : par marque d'origine)** (`home_o` = transferts `"<marque>:<forme>"`, ex. `galar:25`, `za:3-mega` ; `home_og` = sous-ensemble coché depuis la fiche d'un jeu) : une marque d'origine HOME par jeu + ses extensions — Z-A (Z-A + Méga-Dimension), Paldea (Écarlate/Violet + extensions), Hisui (Légendes Arceus), DÉ/PS, Galar (Épée/Bouclier + extensions), Let's Go, GO, trèfle Alola (SL, USUL), pentagone Kalos (X/Y, ROSA), Game Boy (Console virtuelle 3DS : Rouge/Bleu/Jaune, Or/Argent/Cristal, `h: 'vc'`), et « Sans marque » pour la 4ᵉ–5ᵉ génération (DP, Pt, HGSS, N/B, N2/B2 : pas de marque dans HOME, regroupés). Marque GBA (Rouge Feu / Vert Feuille sur Switch) : icône prête (`img/origin/gba.png`), sans bouton tant que ce jeu n'est pas dans la liste « Jeux » (nos Rouge Feu/Vert Feuille sont les versions GBA, non compatibles). Non compatibles : Rubis/Saphir/Émeraude, Rouge Feu/Vert Feuille GBA.
- **Règles v22** : le bouton « Transféré » d'une fiche de jeu (icône de la marque du jeu) et le bouton de la marque sur la fiche **Pokémon HOME** modifient le **même** état. Depuis un jeu : implique « Capturé » dans ce jeu. Depuis la fiche HOME (transfert ou Pokémon reçu par échange dans HOME) : **aucun** « Capturé » dans le jeu. Décocher « Capturé » dans un jeu retire le transfert de sa marque **seulement** s'il a été coché depuis une fiche de jeu et qu'aucun autre jeu de la même marque (ex. X/Y ↔ ROSA) n'a ce Pokémon capturé ; un transfert coché depuis HOME n'est jamais retiré par les jeux. **HOME doré (v23, règle choisie)** = transféré avec toutes les marques **de l'ère Switch** où il existe : Let's Go, Galar, DÉ/PS, Hisui, Paldea, Z-A, + Pokémon GO (sauf fabuleux) et plus tard GBA (Rouge Feu / Vert Feuille Switch) ; Méga Z-A : marque Z-A seule. Les anciens jeux (Game Boy / Console virtuelle, pentagone, trèfle, « Sans marque ») gardent boutons et marques mais ne comptent **pas** (fermeture de Pokémon Bank) ; la fiche HOME les sépare (« Compte pour la dorure » / « Anciens jeux », boutons en pointillés). Une forme sans aucune marque Switch/GO ne peut pas être dorée. Jeux GBA d'origine (Rubis/Saphir/Émeraude, Rouge Feu/Vert Feuille GBA) : aucun lien direct avec HOME (Pal Park → 4ᵉ gén. → Poké Transfert → Bank) → bouton « Transféré » grisé, aucune marque ; un Pokémon venu par ce chemin se coche « Sans marque » sur la fiche HOME (ancien jeu, hors dorure). Les marques « hors dex » éventuelles s'affichent sur la fiche HOME mais ne comptent pas. **Migration** (une fois, au premier lancement v22) : `home_g` / `homeshiny_g` (par jeu) → `home_o` + `home_og` (jeu → marque), `home_g` conservé tel quel en sauvegarde ; l'import d'une ancienne sauvegarde est converti de la même façon. Icônes des marques : **Bulbagarden Archives** (usage équitable), hébergées dans `docs/img/origin/` (pas de lien direct), voir `CREDITS.txt`.
- **Sauvegardes partagées** : un jeu et ses extensions forment une seule sauvegarde (`base` dans `build/games.mjs` : Épée/Bouclier + Isolarmure + Couronneige, Écarlate/Violet + Masque Turquoise + Disque Indigo, Légendes Z-A + Méga-Dimension). Marquer capturé / shiny / transféré dans l'un l'applique à tous les jeux du groupe où le Pokémon existe ; les compteurs et les complétions (Switch, HOME) comptent un groupe une seule fois. Au démarrage et après import, les anciennes marques sont fusionnées par union dans chaque groupe (rien n'est perdu).
- **Variantes de combat** (`bo` dans `core.json`, liste documentée dans `build/battle.mjs`) : formes qui n'existent qu'en combat (Méga, Primo, Éternamax + liste explicite : Morphéo météo, Ceriflor ensoleillé, Darumacho Transe, Meloetta Danse, Amphinobi Sacha/Synergie, Exagide Assaut, Zygarde Parfaite, Froussardine Banc, Météno noyaux, Mimiqui démasqué, Ultra-Necrozma, Nigosier Gobe-Tout/Gobe-Chu, Bekaglaçon Tête Dégel, Morpeko Affamé, Superdofin Super, Terapagos Téracristal/Stellaire). **Mégas** — listées dans tous les jeux à Méga-Évolution (X/Y, ROSA, Soleil/Lune, USUL, Let’s Go, Z-A, Méga-Dimension) avec leurs attaques ; hors Z-A ce sont des variantes de combat (marques de la base, non comptées) ; en Légendes Z-A elles comptent pour la complétion jeux actuels et HOME ; dans Pokémon GO (v28) elles se marquent comme formes GO, hors dorure (voir « v28 ») : bouton sprite-only sur la fiche (pierre FR en tooltip ; X/Y = pierres distinctes ; à défaut sprite **Gemme Sésame** / `key-stone` + libellé Méga-Gemme) ; capturé/shiny en Z-A = forme de base capturée (shiny) dans la sauvegarde Z-A **et** gemme obtenue. Transfert HOME de la Méga : manuel, sauf si gemme cochée — transférer la base transfère aussi la Méga. **Les formes Gigamax se marquent séparément** (Capturé / Shiny / Transféré), car il faut les capturer en jeu. Les autres variantes de combat (Méga, Primo, Éternamax, etc.) ne se marquent pas séparément : elles héritent des marques de la forme de base (« Variante de combat – suit la forme de base »), restent visibles dans la liste Formes et ne comptent pas dans les totaux. Les marques existantes posées sur ces variantes sont reportées sur la forme de base à la migration.
- Vue **Pokémon HOME** (liste) : marques = transferts par marque d'origine (🏠 au moins une marque, 🟡🏠 toutes les marques possibles, ✨ shiny transféré — ancienne donnée par jeu). Fiche : sélecteur « Vue d'ensemble (infos générales) » (lecture seule) ou « Pokémon HOME (transferts) » : la barre d'actions affiche alors un bouton par marque d'origine possible (sur téléphone : 6 par ligne, retour à la ligne, sans débordement).

## Mise en page des fiches (v21)
- **En-tête collant** : ← retour, ‹ › précédent / suivant, ★ favori — rien d'autre.
- **Barre d'actions fixe**, même ordre partout : **Capturé · Shiny · Transféré (HOME) · Méga-Gemme / Méga-énergie**. Un bouton qui ne s'applique pas reste à sa place, grisé. Sur téléphone (< 700 px) la barre est collée en bas de l'écran (zone du pouce) ; sur ordinateur, sous l'en-tête. Le bouton « Shiny transféré » a été retiré (données `homeshiny_g` conservées ; le filtre « Shiny transférés » est masqué en attendant la refonte des fiches HOME).
- **Corps** : héros (sprite, noms, types) → sélecteur de jeu + texte de suivi (sans boutons) → formes → description → stats (+ faiblesses) → talents (+ objets tenus) → capacités → évolutions → rencontres → jeux → Pokémon GO. Contexte GO : stats + PC max, attaques rapides / chargées, évolutions (bonbons), compagnon / œufs.
- **Méga-Gemmes** (`mega_gems`, clés `"<sauvegarde>:<forme Méga>"`, ex. `za:3-mega`, `oras:3-mega`) : bouton sur les fiches de base et Méga des formes qui ont une Méga, dans chaque jeu où la Méga existe (X/Y, ROSA, SL, USUL, Let's Go, Z-A, Méga-Dimension), grisé ailleurs ; un état par pierre partagé entre les formes, par sauvegarde. Hors Z-A : simple marque de possession (les Méga restent des formes de combat, aucun effet sur la complétion). Z-A : règles inchangées (base capturée + gemme = Méga capturée). Les anciennes clés sans préfixe sont migrées vers `za:`.
- **Méga-énergie GO** (`mega_energy` : une marque par espèce, `"3"`, ou une par Méga quand l'espèce en a deux — v22 : `"6-x"`, `"6-y"`, `"150-x"`… ; un ancien `"6"` est migré vers X et Y) : remplace la gemme sur les fiches GO des espèces dont une Méga est sortie dans GO (`go.r` de la forme Méga). Icônes `docs/img/energy/{id}.webp` (et `{id}-x/-y/-z.webp` par Méga, couleurs `0006_MEGA_X` etc.) générées par `build/make-mega-energy.py` à partir des assets minés PokeMiners (`pogo_assets` : forme générique `megaTutorial_energyIcon.png` + couleurs par espèce `PokemonMegaCandyAkaMegaEnergy.json`), icône générique en secours.
