# Revue des formes, suite : jeux, HOME, GO

*11/10/2026. Recherche seulement : l’app n’est pas modifiée.*

## Décisions de Yann (actées)
- Les formes (b) restent séparées.
- **Papilord, Lépidonille, Pérégrain** : une seule forme (fusionner les capes et les motifs invisibles).
- **Xerneas, Koraidon, Miraidon** : comptent pour 1. Leurs autres formes (Mode Paisible, formes de déplacement) deviennent des formes de combat qui héritent des marques de la base.

## Ce qui a été vérifié
- **Dex des jeux** : depuis Noir / Blanc (comparateur de formes) et dans tous les jeux suivants, le Pokédex enregistre chaque forme vue (galerie de formes). La complétion compte quand même les espèces, pas les formes (exemple : Z-A, 230 espèces).
- **Exceptions, le dex ne distingue pas les formes** :
  - Gén. 3 : une seule forme affichée ;
  - Gén. 4 : seule la 1re forme vue est enregistrée (Bulbapedia, page Shaymin) ;
  - Genesect et Arceus : formes enregistrées seulement depuis ROSA ;
  - Couafarel : coupes non enregistrées dans X / Y uniquement.
- **Z-A** affiche chaque forme sur sa propre ligne du dex : Couafarel (10), Zygarde (10 % / 50 %) dans le dex de Lumiose ; Motisma (6), Keldeo, Genesect (5), Hoopa dans le dex de l’Hyperespace.
- **HOME** : le Pokédex enregistre chaque forme reconnue par les jeux. Trois cas :
  - formes à objet tenu ou de combat : enregistrées automatiquement dès qu’une forme quelconque est déposée (Dialga, Palkia et Giratina Originels, Arceus, Genesect, Silvallié, Ogerpon, Zacian, Zamazenta) ;
  - fusions : enregistrées dès que les deux Pokémon qui les composent sont enregistrés ;
  - autres formes : il faut déposer la forme elle-même.
  - À noter : le Guide Pokémon de HOME, lui, n’a pas d’entrée par coupe de Couafarel. C’est le Pokédex qui enregistre les coupes.
- **GO** : chaque forme est enregistrée à part (silhouette dans « À proximité », échange spécial). Elle est fixée à la capture, sauf pour Shaymin, Kyurem, Couafarel, Hoopa, Zygarde, Necrozma, Zacian, Zamazenta et Keldeo, qui peuvent changer de forme.
- Rouge Feu / Vert Feuille (Switch) et Let’s Go ne contiennent aucune de ces 27 espèces.

**Légende.**
- **S\*** : séparer les marques, mais le même individu peut changer de forme dans ce jeu → ajouter un raccourci « cocher toutes les formes ».
- **S** : séparer (formes fixes).
- **L** : lier (une seule marque, le dex ne distingue pas les formes).
- **—** : forme inexistante dans ce jeu, ou changement impossible.
- **auto** : HOME enregistre la forme tout seul → lier.

## Corrections de la 1re revue
- Cheniti change aussi de cape dans Légendes Arceus (selon la zone).
- Vivaldaim et Haydaim changent aussi de forme dans ÉV : la forme dépend de la zone où le jeu est chargé.
- Motisma : il existe aussi un catalogue Motisma dans DÉPS (hors périmètre de l’app).
- Hoopa : le Vase Scellé existe dans Z-A Méga-Dimension (mission 196).
- Genesect : les Modules s’achètent dans Z-A Méga-Dimension (mission 191).

## Écarts relevés dans les données GO de l’app
PvPoke et Bulbapedia donnent ces formes comme sorties dans GO, mais l’app les marque absentes : Zygarde 10 %, Plumeline Pom-Pom, Necrozma Crinière du Couchant / Ailes de l’Aurore, Zacian Épée Suprême, Zamazenta Bouclier Suprême. À corriger dans go-overrides.json (à décider).
